# Zerfallslabor · Physik 10

Simulation zum radioaktiven Zerfall: 50 bis 5 000 Atome, Halbwertszeit 1 bis 10 s,
Klick nach jeder Halbwertszeit, Strahlermeter (stark · mittel · schwach), Kurven
N(t) = N₀ · e^(−λt) und Aktivität A = λ · N live, Messprotokoll, 8 Forscheraufträge.

Lehrkraft-Ansicht mit Erwartungen: `?loesungen` an die Adresse hängen.

Paul-Klee-Gymnasium Overath · Hintergrundbilder KI-erzeugt und stilisiert.
